
# nhp_tpma_rationale

<!-- badges: start -->
<!-- badges: end -->

A simple interactive table in a Quarto doc to explore New Hospital Programme (NHP) schemes' rationale for their choice of types of potentially-mitigatable activity (TPMAs) and prediction intervals.
Shows only scenarios tagged with a run stage of 'validation_report_ndg2' otherwise 'final_report_ndg2', i.e. the primary scenario used in output reports.

[Deployed to Posit Connect](https://connect.strategyunitwm.nhs.uk/nhp/tpma-rationale/) and re-rendered on schedule (login/permissions required).

## Render locally

If you need to generate the report on your machine:

1. Create a `.Renviron` file in the project root using `.Renviron.example` as a template.
Ask a member of the Data Science team for the values required by each variable.
You won't need to include `CONNECT_*` variables if you've already [configured your publishing account in RStudio](https://docs.posit.co/connect/user/publishing-rstudio/).
2. Open `index.qmd` in RStudio and click the 'Render' button if in RStudio (otherwise `quarto::quarto_render()` or via the Quarto CLI).

## Redeploy

If you make changes to the code in this repo, you can redeploy it to our Connect server by running `deploy.R`.

## Refresh

The report runs on schedule, so any changes to the underlying data will be integrated on the next rendering.
You may wish to manually refresh the app from Posit Connect if you want your changes to appear more quickly.
To do this, open the app from the Posit Connect 'Content' page and click the 'refresh report' button (circular arrow) in the upper-right of the interface.

## Data

The data processed by the report is collected from:

* a local `reference/nhp-schemes-lookup.csv` file
* the TPMA lookup in [the TPMAs repo](https://github.com/The-Strategy-Unit/TPMAs)
* [params](https://connect.strategyunitwm.nhs.uk/content/2784320a-dfa4-4694-866f-9c84741568da) and [metadata](https://connect.strategyunitwm.nhs.uk/content/022974aa-dd54-4e33-aed3-42c34f81bc9d) pins generated by [the deployed, scheduled Quarto report](https://connect.strategyunitwm.nhs.uk/nhp/tagged-runs-params-report/) from [the nhp_tagged_runs_params repo ](https://github.com/The-Strategy-Unit/nhp_tagged_runs_params)
